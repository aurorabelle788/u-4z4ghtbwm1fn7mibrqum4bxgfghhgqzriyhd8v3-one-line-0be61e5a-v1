A tiny stdlib-only Python program that writes one original funny line to
`/output/entry.txt`:

> I asked the void for a sign; it replied 'seen 2:47 AM'.

## Run

```sh
python3 main.py
```

Set `OUTPUT_PATH` to write somewhere else (the grader runs it with
`/output/entry.txt`).
